# История версий

Формат по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация по [SemVer](https://semver.org/lang/ru/).

## [1.6.0] — 2026-10-27

### Исправлено
- **Выпадающие пункты меню были не видны.** Цвет задавался строке меню, но
  выпадающие списки наследуют его не от неё, а от своего владельца с системным
  чёрным текстом — на тёмном фоне получалось чёрным по чёрному. Теперь цвет
  проставляется всему дереву пунктов.

### Добавлено
- **Стартовый экран** — пока не открыт ни один файл, видны крупные кнопки
  «Новый проект», «Новый Java-проект», «Открыть проект» и список недавних.
- Горячие клавиши: `Ctrl+N` — новый проект, `Ctrl+Shift+N` — новый Java-проект,
  `Ctrl+O` — открыть проект.

## [1.5.1] — 2026-10-27

### Исправлено
- Рантайм не попадал внутрь `DupoStudio.exe`: ресурсы добавлялись на
  `BeforeTargets="CoreCompile"`, а MSBuild выполняет зависимости цели раньше
  хуков `BeforeTargets`, поэтому список ресурсов к тому моменту уже собран.
  Теперь цепляемся к `AssignTargetPaths` — началу ресурсной цепочки.
- Обе сборки проверяют результат по именам вшитых ресурсов прямо в байтах
  файла, так что пустой exe в релиз больше не уедет.

## [1.5.0] — 2026-10-27

### Изменено
- **Студия раздаётся одним файлом.** `DupoLang.dll` и `DupoHost.exe` лежат
  ресурсами внутри `DupoStudio.exe`: библиотека подхватывается из ресурса при
  загрузке, рантайм распаковывается на диск только когда нужно собрать
  приложение. В релизе теперь сам `DupoStudio.exe`, а не архив.
- Сборка «папкой с файлами» кладёт один exe рядом с исходниками —
  отдельная `DupoLang.dll` больше не нужна.
- `DupoHost` без вшитого приложения ищет `main.dupolang` или `.dapp` рядом с собой.

## [1.4.0] — 2026-10-27

### Добавлено
- **Главный файл как в nginx.** Третий параметр `Web.Server` — имя без
  расширения (`"index"`). Открытая папка отдаёт первый найденный
  `index.html`, `index.php`, `index.js`, `.json`, `.txt`, `.xml`
  вместо ошибки 404.
- Адрес без расширения пробуется как файл: `/about` → `about.html`, `about.php`.
- Папка без завершающей косой черты перенаправляется на `/папка/`,
  чтобы не ломались относительные ссылки внутри страницы.
- `site.SetIndex("index.php, index.html")` задаёт порядок перебора,
  `site.IndexName` и `site.IndexFiles` показывают текущий.
- `site.Fallback = true` — отдавать корневой index на любой неизвестный
  адрес, для приложений на JavaScript.

### Изменено
- Имя с расширением (`"index.php"`) по-прежнему работает — оно просто
  встаёт первым в очереди.

## [1.3.0] — 2026-10-27

### Добавлено
- **Модуль `Dupo.System.Files`** — создание файлов и управление ими: запись,
  дозапись, чтение построчно, замена текста внутри файла, копирование,
  перенос, переименование, размер и дата, работа с папками, поиск по маске
  во вложенных папках, zip-архивы.
- **Модуль `Dupo.Java`** — разработка на Java: `Java.Install()` скачивает
  Temurin JDK с adoptium.net в `runtime\jdk`, затем `Compile`, `Jar`, `Run`,
  `RunJar` и `Build` собирают и запускают программу.
- **`using`** работает как синоним `import`.
- Модуль `Dupo.System` — общая точка входа: `System.Files`, `System.Java`, `System.Sys`.
- Студия: пункт «Новый Java-проект», установка и удаление JDK в «Инструментах»,
  подсветка синтаксиса Java в редакторе, индикатор JDK в статус-баре,
  цвета для `.java`, `.jar` и `.class` в дереве проекта.
- Примеры `Projects/HelloJava` и `Projects/FilesDemo`.

## [1.2.0] — 2026-10-27

### Добавлено
- **Сборка проекта в один `.exe`** (Запуск → Собрать в один .exe, Ctrl+B).
  Новый проект `DupoHost` — рантайм, в который язык вкомпилирован исходниками,
  поэтому `DupoLang.dll` собранному приложению не нужна.
- `DappBundle` — архив дописывается в хвост PE-файла с меткой `DAPPBND1`,
  длиной и CRC32. При старте рантайм читает сам себя и разворачивает приложение
  во временную папку.
- Ключ `console: off` в манифесте прячет консольное окно.
- Иконка приложения, нумерация строк в редакторе, цвета файлов в дереве проекта,
  переделанный статус-бар с индикатором PHP.
- Сайт проекта в `docs/` и workflow для автосборки релизов.

## [1.1.0] — 2026-10-27

### Добавлено
- **Формат `.dapp`** — собственный контейнер приложения: сигнатура `DAPP`,
  версия формата, манифест, записи с Deflate и CRC32, завершитель `DEND`.
- Модуль `Dupo.App`: `Export`, `Import`, `Unpack`, `Info`, `Files`.
- Экспорт (Ctrl+E) и импорт `.dapp` в студии.
- `DupoRun.exe app.dapp` запускает архив напрямую.

### Безопасность
- Пути с `..` и абсолютные при распаковке отбрасываются.
- Несовпадение CRC32 — архив объявляется повреждённым с именем файла.

## [1.0.0] — 2026-10-27

### Добавлено
- **Язык DupoLang**: лексер, парсер, интерпретатор, мост к .NET через рефлексию.
  Переменные с типом и `var`, `if/else`, `while`, `for`, `func`, массивы,
  19 встроенных функций.
- Модули `Dupo.Web`, `Dupo.IO`, `Dupo.Sys`.
- `Web.Server` — статика с MIME-типами и `.php` через `php-cgi.exe` по CGI.
- `Web.Server.Php.Install()` — скачивание и установка PHP с windows.php.net.
- **Dupo Studio** на WinForms: тёмная тема, подсветка синтаксиса, дерево проекта,
  вкладки, консоль вывода, F5.
- `DupoRun` — консольный рантайм.
