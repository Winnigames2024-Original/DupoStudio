## [Не выпущено]

### Сервисы
- Модуль `Dupo.Services`: `Services.Service` и десять типов
  `Services.ServiceLevel` — от `SystemProcess` до `Background`.
- `Install`, `Uninstall`, `Start`, `Stop`, `Restart`, `Info`, свойства
  `Installed`, `Running`, `State`, `NeedsAdmin`.
- Службы системы ставятся через `sc.exe`, процессы пользователя — через
  автозапуск в реестре, так что права администратора нужны не всегда.
- Фоновый сервис самой студии: `DupoStudio.exe --agent`. Меню
  «Инструменты → Фоновый сервис»: установка, запуск, остановка, журнал
  и «Собрать проект в фоне» — очередь заданий переживает закрытие студии.
- Подсказки знают про `Services.`, `Services.ServiceLevel.` и про
  переменные, объявленные типом из API.
- Пример `Projects/ServiceDemo`.

### Типы проектов
- Окно **«Новый проект»** как в Visual Studio: разделы слева, шаблоны
  в середине, описание справа, имя и расположение снизу.
- Десять шаблонов: DupoLang (веб, консоль, сервис), C# (консоль,
  WinForms, библиотека), C++ (консоль, окно на WinAPI), Java
  и **Установщик приложения** с папкой `payload`.
- `Dupo.CSharp` — сборка C# через `csc.exe` из .NET Framework 4.8:
  `Build`, `Forms`, `Library`, `Compile`, `Run`, `Launch`.
- `Dupo.Cpp` — сборка C++ через g++: `Install` скачивает MinGW-w64,
  `Build`, `Window`, `Compile`, `Run`, `Launch`.
- `Dupo.System.Files` пополнился системными папками (`AppData`,
  `Desktop`, `StartMenu`, `ProgramFiles`, `Documents`) и `Shortcut` —
  из этого и собирается установщик.

## [0.0.1] — 2026-10-27

Первый выпуск. Автор — Winnigames2024, продукт — Dupo Studio.

### Язык DupoLang
- Лексер, парсер, интерпретатор, мост к .NET через рефлексию.
- Переменные с типом и `var`, `if/else`, `while`, `for`, `func`, массивы,
  19 встроенных функций. `import` и `using` равноправны.
- Модули `Dupo.Web`, `Dupo.Java`, `Dupo.System.Files`, `Dupo.App`,
  `Dupo.Tools`, `Dupo.Resources`, `Dupo.IO`, `Dupo.Sys`.

### Веб
- `Web.Server` раздаёт статику и отдаёт `.php` через `php-cgi.exe` по CGI.
- Главный файл задаётся без расширения: открытая папка отдаёт первый найденный
  `index.html`, `index.php`, `index.js` — как в nginx.
- `Web.Server.Php.Install()` скачивает и ставит PHP с windows.php.net.

### Java
- `Java.Install()` ставит Temurin JDK в `runtime\jdk`.
- `Compile`, `Jar`, `Run`, `RunJar`, `Build` — сборка и запуск программы.

### Файлы и ресурсы
- `Dupo.System.Files` — около 30 функций: запись, чтение построчно, замена
  текста внутри файла, копирование, поиск по маске, zip-архивы.
- `Dupo.Resources` — файлы из папки `Resources` проекта доступны как
  `Resources.имя`: путь, байты, текст, размер.

### Формат .dapp
- Свой контейнер: сигнатура, манифест, Deflate и CRC32 на каждую запись.
- Сборка проекта в один `.exe` — архив дописывается в хвост рантайма.

### Студия
- Стартовое окно и окно проекта с тремя встроенными окнами: дерево,
  редактор с вкладками, вывод.
- **Свойства проекта** (Alt+Enter): название, продукт, автор, версия,
  описание, пространство имён, пакет Java, галочка «Собирать в один exe»
  и список ресурсов с добавлением файлов.
- **Подсказки в редакторе**: после точки за модулем и по Ctrl+Пробел.
  `Resources.` подсказывает именно те файлы, что добавлены в проект.
- Автозапуск проекта: при закрытии студия спрашивает, открывать ли его сразу.
- Студия раздаётся одним файлом: `DupoLang.dll` и `DupoHost.exe` внутри exe.

### Утилиты командной строки
- `DupoBuild.exe` — сборка папки в один `.exe`, всё через аргументы.
- `DupoLang.exe` — перевод `.dupolang` в C#.
- Едут внутри установщика и разворачиваются вместе со студией,
  так что интернет не нужен.

### Установщик
- `DupoStudioSetup.exe` — установка для пользователя, без прав администратора:
  ярлыки, запись в список программ, связывание `.dupolang` и `.dapp`, удаление.
