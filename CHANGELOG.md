# История версий

Формат по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация по [SemVer](https://semver.org/lang/ru/).

## [0.0.6] — 2026-10-27

### Python
- Новый модуль **`Dupo.Python`**: `Python.Install()` скачивает переносимый
  Python с python.org в `runtime\python`. В систему ничего не прописывается,
  системный Python не затрагивается — а если он уже есть, берётся он.
- `Python.Run` (файл, с аргументами), `Python.Code` (строка кода),
  `Python.Check` (синтаксис), `Python.Pip` и `Python.Packages` (пакеты
  в свой `site-packages`), `Python.Build` — один `.exe` через PyInstaller,
  который доставится сам.
- Три новых шаблона проектов: «Консольное приложение», «Приложение
  с пакетами (pip)» и «Приложение Python + DupoLang».
- Пример `Projects/PythonDemo`.

### C++
- `Cpp.Library` — сборка `.dll` через `-shared`, и шаблон проекта
  «Библиотека (.dll)» с готовым заголовком и `EXPORT`.
- `Cpp.Debug` — сборка с отладочными сведениями, без оптимизации.

### Свои темы на C#
- **Вид → Тема → Своя тема (C#)**: файл `theme.cs` в `%APPDATA%\DupoStudio`
  компилируется настоящим `csc.exe` и задаёт оформление студии:
  `background.color = "#101014"; background.image = "C:\fon.jpg";`
  и так для двадцати частей интерфейса — панели, рамки, текст,
  подсветка синтаксиса, цвета ошибок.
- У фона есть `fit` (`cover`, `stretch`, `tile`, `center`) и `opacity`,
  так что картинка не перебивает текст.
- Пункт «Открыть файл темы...» создаёт заготовку с комментариями.
  Выбранная тема запоминается и поднимается при следующем запуске;
  если файл сломан, студия остаётся на встроенной палитре.

### Установка
- Установщик и `uninstall.exe` перед копированием ищут процессы,
  которые держат файлы, показывают их списком и по согласию закрывают —
  вместо падения «файл используется другим процессом» на середине.
  Что не закрылось, названо по имени.

## [0.0.5] — 2026-10-27

### Помощник правит файлы
- Помощник теперь не только отвечает, но и **меняет файлы проекта**:
  создаёт, переписывает, дописывает, заменяет куски и удаляет.
- Правки не применяются молча: студия показывает список и кнопки
  «Применить» и «Не надо». Прежние файлы складываются в `.dupo/backup`.
- Пути проверяются — за пределы проекта помощник не выйдет.
- В разговор уходит содержимое файлов проекта, так что он видит код.

### Окна на DupoLang
- Модуль **`Dupo.Forms`**: окно собирается прямо на DupoLang, без C#.
  `Forms.Open("Form1.dupoform")`, `On`, `Get`, `Set`, `Checked`, `Push`,
  `Clear`, `SetImage`, `Enable`, `ShowItem`, `Show`, `Close`,
  а ещё `Forms.Message` и `Forms.Ask`.
- Шаблон **«Windows Forms + DupoLang»** переделан: папки `src` нет,
  форма лежит в `.dupoform` и правится конструктором, запускает её
  `program.dupolang`, а методы берутся из других файлов DupoLang
  через `Lang.ExecuteFrom`.
- События: `click`, `change`, `select`, `close`.

### Ресурсы
- Папка ресурсов теперь **`assets`**; старая `Resources` ещё читается,
  так что прежние проекты работают как работали.

### Ollama
- Кнопка **«Поставить Ollama»** в настройках помощника: скачивает
  установщик, ставит его тихо и подтягивает модель `qwen2.5-coder`.
- Если Ollama установлена, но не запущена, студия поднимает её сама.

## [0.0.4] — 2026-10-27

### Запуск и сборка
- **Запуск теперь как в Visual Studio**: F5 собирает проект в `.exe`
  и запускает уже его, вывод идёт в окно «Вывод». Прежнее поведение
  осталось на Ctrl+F5 — «Запустить без сборки».

### Типы проектов
- **Консольное приложение + DupoLang** и **Windows Forms + DupoLang**:
  логика в `logic.dupolang`, C# зовёт её блоки через
  `Dupo.Lang.ExecuteFrom`, ссылка на библиотеку подставляется сама.

### Панель элементов
- Вторая вкладка — **«Библиотеки»**: список сборок .NET с галочками
  и кнопка «Добавить .dll...». Отмеченные пишутся в `project.dupo`
  строкой `references=`, а `Dupo.CSharp` сам подставляет их при сборке.

### Подсказки и помощник
- Подсказки появляются **по ходу набора**, а не только после точки
  и по Ctrl+Space; внутри строк и комментариев не мешают.
- Помощник умеет спрашивать **Ollama на этом компьютере** — бесплатно
  и без ключа. Настройка проверяет, запущена ли она, и показывает
  скачанные модели.

## [0.0.3] — 2026-10-27

### Сайт
- Адреса без `.html`: главная — `/`, загрузки — `/releases/`.
- Своя страница у каждой версии: **`/release/<версия>/`** — там все файлы
  выпуска, исходники zip и tar.gz и заметки. Страницы собираются при
  выкладке сайта и появляются сами, как только выходит новая версия.
- `/release/` — список версий, `/release/latest/` ведёт на свежую.

### Оформление
- **Темы**: Тёмная, Светлая, Синяя ночь, Контрастная, Тёплая.
  Меню «Вид → Тема», выбор применяется сразу и запоминается.
- Починен стартовый экран: подпись больше не залезает под кнопку,
  список недавних проектов не наезжает на подсказку, карточка
  подстраивается по высоте.
- Выбор папки везде — обычное окно проводника с адресной строкой
  и закладками, а не маленькое дерево.

### Установка и обновление
- Установщик переделан в привычный мастер: приветствие, выбор папки
  со свободным местом, дополнительные задачи, сводка, ход установки
  и завершение — с кнопками «Назад», «Далее», «Отмена».
- **`uninstall.exe`** — отдельная маленькая программа, а рядом
  **`uninstall.dll`** с данными об установке: что за приложение, какой
  версии, чьё, куда поставлено, какие файлы, ярлыки и записи в реестре
  за ним убирать. Окно удаления — обычное: вопрос, затем полоска хода.
- **`update.exe`** — обновление с GitHub. Порядок: сначала приложение,
  затем новый `update.exe` откладывается рядом, потом инструменты сборки,
  и уже на выходе обновлятор меняет сам себя. Есть `/check` и `/silent`.
  В студии: Справка → «Проверить обновления».
- `update.exe` и `uninstall.exe` теперь и отдельные файлы выпуска.

### Помощник
- Панель **«Помощник»** (Ctrl+Alt+A) с отдельным чатом на каждый проект —
  история живёт в `<проект>/.dupo/assistant.json`.
- Знает язык DupoLang, C# вместе с `Designer.cs`, Java и связку между ними,
  все модули и команды; отвечает без интернета по своей базе знаний.
- Кнопка «Вставить код» переносит блок из ответа прямо в открытый файл.
- «Настроить сервис»: адрес, ключ и модель сервиса, совместимого с OpenAI.
  Ключ хранится только на этом компьютере и в проект не попадает;
  если сервис не отзовётся, помощник возвращается к своей базе знаний.

### def-блоки и связка с C#
- Слово **`def`** — полный синоним `func`.
- **`Dupo.Lang.ExecuteFrom("файл.dupolang", "имяDef", аргументы...)`** вызывает
  один блок, не выполняя остальной код файла. Рядом `TextFrom`, `NumberFrom`,
  `TruthFrom`, `Functions`, `HasFunction`, `Arity`, `Run`, `Code`, `Check`,
  `Output`, `Reset`. Разобранные файлы кешируются по времени правки.
- Из C# вызывается буквально так же — класс лежит внутри `DupoLang.Dupo`.
  В DupoLang то же доступно через `using Dupo.Lang`.
- `Dupo.CSharp` сам подставляет ссылку на `DupoLang.dll`, если код её зовёт,
  и кладёт библиотеку рядом с собранным exe.
- Рефлексия научилась раскрывать `params`, поэтому вызовы с любым числом
  аргументов находят нужный метод.

### Дизайнер Windows Forms
- Конструктор читает и пишет **`Form1.Designer.cs`**: разбирает
  `InitializeComponent`, собирает его заново и сохраняет обычный C#.
- Проект → **Новая форма Windows Forms...** создаёт пару `Form1.cs`
  и `Form1.Designer.cs`, а при нужде и `Program.cs`.
- **F7** переключает конструктор и код, как в Visual Studio.
  Двойной щелчок по элементу создаёт обработчик `имя_Click`
  в `Form1.cs` и открывает его.
- Шаблон «Windows Forms» теперь создаёт форму парой файлов,
  так что её сразу можно открыть в конструкторе.

### Данные в языке
- Тип **словарь**: `Data.Map`, индексация `m["имя"]` на чтение и запись,
  встроенные `map()`, `keys()`, `values()`, `has()`, `len()` понимает словари.
- `Dupo.Json` — свой разбор и запись JSON без сторонних библиотек:
  `Parse`, `Read`, `Text`, `Pretty`, `Save`. Объект становится словарём,
  массив — списком.
- `Dupo.Text` — три десятка функций для строк: обрезка, регистр, поиск,
  разбиение на строки и слова, склейка, шаблоны `{0}` и `{имя}`,
  регулярные выражения, Base64 и экранирование для адресов.
- Пример `Projects/DataDemo`, проверяется в CI.

## [0.0.2] — 2026-10-27

### Сервисы
- Модуль `Dupo.Services`: `Services.Service` и десять типов
  `Services.ServiceLevel` — от `SystemProcess` до `Background`.
- `Install`, `Uninstall`, `Start`, `Stop`, `Restart`, `Info`, свойства
  `Installed`, `Running`, `State`, `NeedsAdmin`.
- Службы системы ставятся через `sc.exe`, процессы пользователя — через
  автозапуск в реестре, так что права администратора нужны не всегда.
- Фоновый сервис самой студии: `DupoStudio.exe --agent`. Меню
  «Инструменты → Фоновый сервис»: установка, запуск, остановка, журнал
  и «Собрать проект в фоне» — очередь заданий переживает закрытие студии.
- Подсказки знают про `Services.`, `Services.ServiceLevel.` и про
  переменные, объявленные типом из API.
- Пример `Projects/ServiceDemo`.

### Среда как в Visual Studio
- **Плавающие панели с докингом**: заголовок с кнопками «отцепить»
  и «спрятать», вкладки снизу, зоны слева, справа и внизу.
  Панель вытаскивается в отдельное окно и возвращается при его закрытии.
- **Обозреватель решений** слева, **окно свойств** и **панель элементов**
  справа, **вывод** снизу. Меню **«Вид»** включает и выключает каждую,
  «Вернуть все окна на место» собирает отцепленные обратно.
- Окно свойств — настоящая сетка свойств: категории, подсказки,
  правка на месте. Показывает либо проект, либо выделенный элемент формы.
- **Дизайнер форм**: холст с сеткой, элементы кладутся из панели
  элементов и двигаются мышью, Delete удаляет. Форма хранится
  в `.dupoform`, «Сгенерировать код формы» пишет готовый класс C#.

### Типы проектов
- Окно **«Новый проект»** как в Visual Studio: разделы слева, шаблоны
  в середине, описание справа, имя и расположение снизу.
- Десять шаблонов: DupoLang (веб, консоль, сервис), C# (консоль,
  WinForms, библиотека), C++ (консоль, окно на WinAPI), Java
  и **Установщик приложения** с папкой `payload`.
- `Dupo.CSharp` — сборка C# через `csc.exe` из .NET Framework 4.8:
  `Build`, `Forms`, `Library`, `Compile`, `Run`, `Launch`.
- `Dupo.Cpp` — сборка C++ через g++: `Install` скачивает MinGW-w64,
  `Build`, `Window`, `Compile`, `Run`, `Launch`.
- `Dupo.System.Files` пополнился системными папками (`AppData`,
  `Desktop`, `StartMenu`, `ProgramFiles`, `Documents`) и `Shortcut` —
  из этого и собирается установщик.

## [0.0.1] — 2026-10-27

Первый выпуск. Автор — Winnigames2024, продукт — Dupo Studio.

### Язык DupoLang
- Лексер, парсер, интерпретатор, мост к .NET через рефлексию.
- Переменные с типом и `var`, `if/else`, `while`, `for`, `func`, массивы,
  19 встроенных функций. `import` и `using` равноправны.
- Модули `Dupo.Web`, `Dupo.Java`, `Dupo.System.Files`, `Dupo.App`,
  `Dupo.Tools`, `Dupo.Resources`, `Dupo.IO`, `Dupo.Sys`.

### Веб
- `Web.Server` раздаёт статику и отдаёт `.php` через `php-cgi.exe` по CGI.
- Главный файл задаётся без расширения: открытая папка отдаёт первый найденный
  `index.html`, `index.php`, `index.js` — как в nginx.
- `Web.Server.Php.Install()` скачивает и ставит PHP с windows.php.net.

### Java
- `Java.Install()` ставит Temurin JDK в `runtime\jdk`.
- `Compile`, `Jar`, `Run`, `RunJar`, `Build` — сборка и запуск программы.

### Файлы и ресурсы
- `Dupo.System.Files` — около 30 функций: запись, чтение построчно, замена
  текста внутри файла, копирование, поиск по маске, zip-архивы.
- `Dupo.Resources` — файлы из папки `Resources` проекта доступны как
  `Resources.имя`: путь, байты, текст, размер.

### Формат .dapp
- Свой контейнер: сигнатура, манифест, Deflate и CRC32 на каждую запись.
- Сборка проекта в один `.exe` — архив дописывается в хвост рантайма.

### Студия
- Стартовое окно и окно проекта с тремя встроенными окнами: дерево,
  редактор с вкладками, вывод.
- **Свойства проекта** (Alt+Enter): название, продукт, автор, версия,
  описание, пространство имён, пакет Java, галочка «Собирать в один exe»
  и список ресурсов с добавлением файлов.
- **Подсказки в редакторе**: после точки за модулем и по Ctrl+Пробел.
  `Resources.` подсказывает именно те файлы, что добавлены в проект.
- Автозапуск проекта: при закрытии студия спрашивает, открывать ли его сразу.
- Студия раздаётся одним файлом: `DupoLang.dll` и `DupoHost.exe` внутри exe.

### Утилиты командной строки
- `DupoBuild.exe` — сборка папки в один `.exe`, всё через аргументы.
- `DupoLang.exe` — перевод `.dupolang` в C#.
- Едут внутри установщика и разворачиваются вместе со студией,
  так что интернет не нужен.

### Установщик
- `DupoStudioSetup.exe` — установка для пользователя, без прав администратора:
  ярлыки, запись в список программ, связывание `.dupolang` и `.dapp`, удаление.
