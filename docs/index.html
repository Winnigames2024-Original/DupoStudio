Конструктор приложений со своим языком DupoLang. Веб-сервер и PHP ставятся сами, проект пакуется в собственный формат .dapp и собирается в один самостоятельный исполняемый файл — без DLL рядом.

↓  Скачать Исходники на GitHub
main.dupolang 
// весь сайт с PHP — вот столько кода
import Dupo.Web

Web.Server site = new Web.Server(8080, "www", "index.html")

if (Web.Server.Php.IsInstalled == false) {
    Web.Server.Php.Install()
}

site.Start()
Web.Open(site.Url)

Что внутри

Язык, среда и рантайм — три проекта в одном решении.

⚙

Свой язык

Лексер, парсер, интерпретатор. Переменные с типом и var, ветвления, циклы, функции, массивы, 19 встроенных функций.

🌐

Веб-сервер в одну строку

Статика с MIME-типами и защитой от выхода за корень, а .php уходит в php-cgi.exe по честному CGI: $_GET, $_POST, заголовки, редиректы.

🐘

PHP ставится сам

Web.Server.Php.Install() читает список релизов с windows.php.net, качает свежий NTS x64, распаковывает и пишет готовый php.ini.

📦

Формат .dapp

Собственный контейнер: сигнатура, манифест, Deflate и CRC32 на каждую запись. Не переименованный zip.

🚀

Сборка в один exe

Архив дописывается в хвост рантайма, в который язык вкомпилирован исходниками. Один файл, никаких DLL.

🎨

Подсветка синтаксиса, нумерация строк, дерево проекта с цветами по типам, консоль вывода, F5 — и поехали.

Как устроен .dapp

Поток пишется и читается за один проход — без оглавления в конце файла.

"DAPP" uint16 версия манифест UTF-8 int32 N записей путь · размер · CRC32 · способ · данные "DEND"

Каждый файл жмётся Deflate и кладётся тем способом, который вышел меньше, — картинки и готовые архивы не раздуваются. При распаковке считается CRC32: не сошлось — архив объявляется повреждённым с именем конкретного файла. Пути с .. и абсолютные отбрасываются.

Сборка в один exe

Windows игнорирует байты после PE-образа — этим и пользуемся.

PE-образ DupoHost.exe байты .dapp int64 длина uint32 CRC32 "DAPPBND1"

При старте рантайм читает сам себя, находит метку, сверяет контрольную сумму, разворачивает приложение во временную папку — один раз, дальше берёт готовое — и запускает главный скрипт из манифеста.
